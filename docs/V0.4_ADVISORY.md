# v0.4 — Evidence-constrained interpretation assistant

This is an **advisory boundary**, not an AI GM and not a new game rules engine.

## Flow

1. Draft an interpretation with `interpretation.draft_interpretation`.
2. Call `evidence_assistant.prepare_advisory(state, proposal)` in a **trusted referee context**, or pass `viewer_id='PC'` to obtain a redacted player-context packet.
3. Optionally send that packet to a model. No provider is bundled and no model output is trusted.
4. Require a structured response containing `context_digest`, `verdict`, `explanation`, and `support_ids` (plus optional `assumptions` and `alternatives`).
5. Call `check_advice` to reject stale context, missing citations, inaccessible references, and malformed replies.
6. If advice is usable, the **human referee/player must still review and approve** the actual proposed world-state change through the existing v0.3 commit protocol.

## Invariants

- **No silent mutations.** Neither advisory function uses the event journal write path.
- **No unrestricted world dump.** Referee packets include only cited facts; player packets include only previously known evidence, public-facing text and non-sensitive fields.
- **No semantic truth claim.** A valid citation shows that a record exists, not that its contents entail the suggested conclusion.
- **No implied authority.** A usable advisory reply is not an approval, game roll, or completed faction action.
- **No stale approvals.** A response is bound to the exact packet via `context_digest`.

## Example

```python
from evidence_assistant import prepare_advisory, check_advice

packet = prepare_advisory(state, proposal)  # trusted referee side only
suggestion = {
    "context_digest": packet["context_digest"],
    "verdict": "uncertain",
    "explanation": "The cited observation does not establish the courier's intent.",
    "support_ids": ["F-LOCK"],
    "assumptions": ["The courier is acting on behalf of the reeve."],
    "alternatives": ["Keep the courier's employer unresolved until observed."]
}
result = check_advice(state, proposal, suggestion)
assert result["reviewer_approval_required"] is True
```

Replace `F-LOCK` with a real cited fact in your campaign. The above is a contract illustration, not a result of a live model call.
